# 🌌 Galactic Empire

Vesmírná grand strategie inspirovaná hrou Stellaris, vytvořená pro webové rozhraní.

## 🎮 Herní mechaniky

### Základní hratelnost
- **4X strategie**: Explore (Prozkoumej), Expand (Roztáhni se), Exploit (Využívej), Exterminate (Zničit)
- **Real-time s pauzou**: Hra běží v reálném čase, můžete ji pozastavit a měnit rychlost
- **Správa říše**: Spravujte zdroje, technologie, populaci a lodě

### Zdroje
- **⚡ Energie**: Základní zdroj pro provoz lodí a budov
- **🔩 Minerály**: Stavební materiál pro lodě a infrastrukturu
- **🧪 Výzkum**: Body pro výzkum technologií
- **🍞 Potraviny**: Nutné pro růst populace

### Herní systémy

#### 🗺️ Průzkum galaxie
- Galaxie obsahuje 50 hvězdných systémů různých typů
- Žluté hvězdy - vysoká obyvatelnost
- Červení obři - střední obyvatelnost
- Modří obři - nízká obyvatelnost
- Bílí trpaslíci - velmi nízká obyvatelnost
- Neutronové hvězdy - neobyvatelné

#### 🚀 Loďstvo
- **Průzkumník** 🛸 - Rychlá loď pro průzkum galaxie
  - Cena: 50 energie, 30 minerálů
  - Vysoká rychlost
- **Korveta** ⚔️ - Bojová loď
  - Cena: 100 energie, 80 minerálů
  - Střední rychlost, vyšší bojová síla
- **Kolonizační loď** 🏗️ - Založení nových kolonií
  - Cena: 200 energie, 150 minerálů, 100 potravin
  - Nízká rychlost, schopnost kolonizace

#### 🔬 Technologie
- **Pokročilá těžba** - Zvyšuje příjem minerálů
- **Plazmové motory** - Rychlejší lodě
- **Laserové zbraně** - Silnější lodě

#### 🏛️ Kolonizace
- Prozkoumejte systém průzkumnou lodí
- Pošlete kolonizační loď do obyvatelného systému
- Založte kolonii pro získání přístupu ke zdrojům systému

## 🎯 Jak hrát

### Ovládání
- **Levý klik na systém** - Výběr systému
- **Pravý klik na systém** (nebo Ctrl + klik) - Poslat vybranou loď
- **Kolečko myši** - Přiblížení/oddálení
- **Střední tlačítko myši** - Posun kamery

### Rychlost hry
- **⏸️ Pauza** - Pozastavit/pokračovat
- **1x, 2x, 4x** - Rychlost hry

### Tipy pro začátek
1. Prozkoumejte okolní systémy průzkumníky
2. Postavte kolonizační loď a kolonizujte obyvatelné systémy
3. Rozvíjejte technologie pro efektivnější správu říše
4. Expandujte postupně a udržujte pozitivní bilanci zdrojů
5. Sledujte růst populace a spotřebu potravin

### Strategie
- **Raný průzkum**: První průzkumníci jsou klíčoví pro nalezení dobrých kolonizačních cílů
- **Ekonomika**: Udržujte pozitivní příjem všech zdrojů
- **Expanze**: Kolonizujte systémy s vysokou obyvatelností a dobrými zdroji
- **Technologie**: Výzkum technologií poskytuje dlouhodobé výhody
- **Populace**: Větší populace = více příjmů, ale vyšší spotřeba potravin

## 🚀 Spuštění

Jednoduše otevřete `index.html` v moderním webovém prohlížeči (Chrome, Firefox, Edge, Safari).

Hra nevyžaduje žádný server ani instalaci - běží čistě v prohlížeči!

## 🛠️ Technické detaily

- **Pure JavaScript** - žádné frameworky, čistý vanilla JS
- **Canvas API** - pro vykreslování galaxie
- **CSS3** - moderní, gradient-based design
- **Responzivní** - přizpůsobí se velikosti okna

## 🎨 Herní design

Hra je navržena jako zjednodušená, ale funkční verze 4X space strategy, která zachycuje základní herní smyčku:
1. Průzkum nových systémů
2. Expanze skrze kolonizaci
3. Využití zdrojů pro růst
4. Výzkum technologií pro zlepšení říše
