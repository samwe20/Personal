# Deníky

Česká revize deníku Karla Schnellera. Texty jsou v `schneller-tagebuch-cs/`, skripty v `scripts/`.

Skripty berou deník ze složky `deniky/`, protože počítají cestu od sebe. Spouštěj je odtud:

```bash
cd deniky
python3 scripts/revise_schneller_translation.py status
```

Soubory pocházejí z větve `cursor/schneller-translator-agent-649a` (21. července 2026). Hra, která na té větvi ležela vedle deníku, tady není.
